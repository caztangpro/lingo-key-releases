# LingoKey Releases

Download links for the [LingoKey](https://lingokey.caztang.com) desktop app.

## Download

Visit the [latest release](https://github.com/caztangpro/lingo-key-releases/releases/latest) to download the installer for your platform.

| Platform | File |
|----------|------|
| Windows  | `.msi` installer |
| macOS    | `.dmg` installer |
| Linux    | `.deb` package |

All binaries are built by [GitHub Actions](https://github.com/caztangpro/lingo-key/actions) and automatically mirrored here.
